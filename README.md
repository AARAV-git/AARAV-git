### 🚀 Featured Projects

#### 🩺 [ORION-Health — Multi-Agent AI Triage System](https://github.com/AARAV-git)
*Python · FastAPI · React · LLMs · Scikit-learn · WebSockets*
A multi-agent system where cooperating agents reason over patient data, run ML-based risk scoring, and generate LLM-driven explanations for real-time triage decisions — built with a human-in-the-loop feedback loop and a full-stack live dashboard.

#### 🧹 Dataset Quality Auditor
*Python · FastAPI · React · LLMs · Pandas*
A multi-agent pipeline of tool-using agents that autonomously analyze datasets, detect quality issues, and execute automated cleaning actions — with a self-learning, self-healing agent loop and a real-time monitoring dashboard.

#### 🧠 Trust-Adaptive AI for Clinical Decision Support — *IEEE IC3ET 2026*
*PyTorch · Hugging Face · BioMed-RoBERTa · NLP*
A trust-adaptive AI framework that dynamically adjusts agent decision behavior based on clinician sentiment, improving interpretability and reliability of AI-assisted decisions. Fine-tuned BioMed-RoBERTa for trust classification — **accepted as first author, IEEE IC3ET 2026.**

#### 💼 CareerStack AI — Career Recommendation Platform *(Live)*
*Python · FastAPI · React · NLP · LLMs · FAISS*
A retrieval-augmented AI platform for resume analysis, ATS scoring, and personalized career recommendations, featuring role matching, learning roadmap generation, and an LLM-based chatbot agent in a scalable production system.
